# DecodeLabs Task 4 - Financial Translation Engine

## Description

The Financial Translation Engine is an enterprise grade JavaFX application that performs real time currency conversion through the Exchange Rate API. It provides a modern banking interface, supports multiple international currencies, validates user input securely, and maintains conversion history with a professional user experience.

This project was developed as part of the **DecodeLabs Internship Program** to demonstrate JavaFX development, API integration, Object Oriented Programming (OOP), exception handling, and enterprise level desktop application design.

## Features

- Enterprise grade modern banking interface
- Real time currency conversion using Exchange Rate API
- Supports 30 international currencies
- Source and Target Currency selection
- Secure monetary amount validation
- Rejects negative values before processing
- Handles invalid and non numeric input using exceptions
- Displays current exchange rate after every conversion
- Swap Currency functionality
- Reset functionality
- Copy converted result to clipboard
- Conversion history using JavaFX TableView
- Progress indicator during API communication
- Network and API exception handling
- Professional dark themed responsive UI
- Clean and user-friendly interface

## Technologies Used

- Java
- JavaFX
- Java HttpClient
- JSON Parsing
- Exchange Rate API
- Object Oriented Programming (OOP)
- NetBeans IDE

## How to Run

1. Open the project in NetBeans IDE.
2. Build the project successfully.
3. Run the application.
4. Enter the amount to convert.
5. Select the source and target currencies.
6. Click the Convert button to perform real time currency conversion.
7. View the exchange rate and conversion history.
